### English

External services ISP Platform contacts, and when. Core job code (`core/*.py`) makes no network calls; downloads happen at image build / manual download, and at runtime only through the Web UI "Download from URL".

### 日本語

ISP Platform が接続する外部サービスと、そのタイミングです。ジョブ本体のコード（`core/*.py`）はネットワークに接続しません。ダウンロードはイメージのビルド時か手動ダウンロード時に行い、実行中に接続するのは Web UI の「Download from URL」だけです。
