### English

`run_isp_umap.py`: embeds end, start and perturbed-start cells and projects them with UMAP to show where the perturbation moves cells. Runs only for targeted gene lists (E2E TOP1 gene, or the ISP UMAP run type), never for genome-wide ISP.

### 日本語

`run_isp_umap.py`: end、start、摂動後の start の細胞を埋め込み、UMAP に投影して、摂動で細胞がどこへ動くかを示します。遺伝子を指定したとき（E2E の TOP1 遺伝子、または ISP UMAP の Run type）だけ実行され、ゲノムワイド ISP では実行されません。
