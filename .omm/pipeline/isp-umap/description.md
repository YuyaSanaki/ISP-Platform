### English

`run_isp_umap.py`: embeds end, start and perturbed-start cells and projects them with UMAP to show where the perturbation moves cells. Runs for one gene or a gene set: in E2E the TOP1 significant gene (genome-wide ISP) or the listed genes perturbed together (gene list), or via the ISP UMAP run type.

### 日本語

`run_isp_umap.py`: end、start、摂動後の start の細胞を埋め込み、UMAP に投影して、摂動で細胞がどこへ動くかを示します。1遺伝子または遺伝子セットについて実行します。E2E ではゲノムワイド ISP なら有意な TOP1 遺伝子、遺伝子リスト指定ならリストの遺伝子をまとめて摂動したもの、あるいは ISP UMAP の Run type から実行します。
