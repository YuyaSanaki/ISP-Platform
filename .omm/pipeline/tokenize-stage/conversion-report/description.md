### English

Runs when ortholog conversion applies (CLI flag > YAML > `should_convert`). Writes `conversion_report.json`, `conversion_report.txt` and `conversion_unmapped_genes.tsv` into `tokenized_dataset/`; the Web UI Output tab lists the dropped genes.

### 日本語

オルソログ変換が入るときに実行されます（優先順位は CLI フラグ > YAML > `should_convert`）。`tokenized_dataset/` に `conversion_report.json`、`conversion_report.txt`、`conversion_unmapped_genes.tsv` を書き、Web UI の Output タブで落ちた遺伝子を一覧できます。
