### English

Ways to start ISP Platform work: Docker image build, Compose services (Web UI and one-shot jobs), direct Python CLIs for runners without a Compose service, the H100 native conda + Slurm/PBS path, and smoke/QA scripts.

### 日本語

ISP Platform の処理を始める方法の一覧です。Docker イメージのビルド、Compose のサービス（Web UI と単発ジョブ）、Compose サービスのないランナー用の Python CLI 直接実行、H100 での conda + Slurm/PBS によるネイティブ実行、スモーク・QA 用スクリプトがあります。
