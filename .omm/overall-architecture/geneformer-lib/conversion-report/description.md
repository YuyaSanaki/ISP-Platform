### English

Builds `conversion_report.json/.txt` and `conversion_unmapped_genes.tsv` (with drop reason and brief gene function) from loom `ensembl_id`s. On by default whenever ortholog conversion applies; `--no-report-conversion` disables it.

### 日本語

loom の `ensembl_id` から `conversion_report.json/.txt` と `conversion_unmapped_genes.tsv`（落ちた理由と遺伝子機能の短い説明付き）を作ります。オルソログ変換が入るときは既定で有効で、`--no-report-conversion` で止められます。
