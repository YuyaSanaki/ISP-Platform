### English

The operator's browser on port 8502 (Compose maps 8502→8501). On a remote GPU server use `ssh -L 8502:localhost:8502`. Two tabs: Analysis and Output.

### 日本語

ポート 8502 で開く操作者のブラウザです（Compose が 8502→8501 に対応づけ）。リモートの GPU サーバーでは `ssh -L 8502:localhost:8502` を使います。タブは Analysis と Output の2つ。
