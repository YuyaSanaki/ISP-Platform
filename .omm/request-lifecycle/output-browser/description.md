### English

Output tab: read-only browser over `pipeline_*` folders under the output root (paths outside it are refused). Shows figures, CSV previews, the dropped-gene panel (from `conversion_report.json` / `conversion_unmapped_genes.tsv`), rank enrichment results when `rank_enrichment/summary.json` exists (figures, top genes and gene-rank CSV downloads) and a run zip that skips `tokenized_dataset/`, `loom_files/` and `checkpoint-*`.

### 日本語

Output タブ: 出力ルート配下の `pipeline_*` フォルダを読むだけのブラウザです（ルート外のパスは拒否）。図、CSV のプレビュー、変換で落ちた遺伝子の一覧（`conversion_report.json` / `conversion_unmapped_genes.tsv` から）、`rank_enrichment/summary.json` があれば rank enrichment の結果（図、上位遺伝子と遺伝子 rank の CSV のダウンロード）、`tokenized_dataset/`・`loom_files/`・`checkpoint-*` を除いた実行の zip を表示します。
