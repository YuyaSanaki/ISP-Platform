### English

Output tab: read-only browser over `pipeline_*` folders under the output root (paths outside it are refused). Shows figures, CSV previews, the dropped-gene panel (from `conversion_report.json` / `conversion_unmapped_genes.tsv`) and a run zip that skips `tokenized_dataset/`, `loom_files/` and `checkpoint-*`.

### 日本語

Output タブ: 出力ルート配下の `pipeline_*` フォルダを読むだけのブラウザです（ルート外のパスは拒否）。図、CSV のプレビュー、変換で落ちた遺伝子の一覧（`conversion_report.json` / `conversion_unmapped_genes.tsv` から）、`tokenized_dataset/`・`loom_files/`・`checkpoint-*` を除いた実行の zip を表示します。
